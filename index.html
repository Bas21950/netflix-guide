เดิมเป็น Windows Home อัปเกรดเป็น Pro ไม่ผ่าน (Error 0x80070490)?

วิธีแก้: ให้ทำการ ตัดการเชื่อมต่ออินเทอร์เน็ต (ปิด Wi-Fi / ดึงสายแลนออก) จากนั้นใส่คีย์เดิมอีกครั้งแล้วกด Activate ระบบจะทำการดาวน์โหลดฟีเจอร์ Pro สำเร็จ เมื่อเครื่องรีสตาร์ทเสร็จค่อยเปิดเน็ตตามปกติครับ

เครื่องเคยลง Crack หรือโปรแกรม KMS เถื่อนมาก่อน?

วิธีแก้: เปิดโปรแกรม Command Prompt (cmd) แบบ Run as administrator แล้วพิมพ์คำสั่ง slmgr /upk กด Enter เพื่อล้างคีย์เก่าออก แล้วค่อยนำคีย์แท้ของทางร้านไปกรอกในหน้า Settings ตามปกติครับ
