เดิมเป็น Windows Home อัปเกรดเป็น Pro ไม่ผ่าน (Error 0x80070490)?

วิธีแก้: ให้ทำการ ตัดการเชื่อมต่ออินเทอร์เน็ต (ปิด Wi-Fi หรือถอดสายแลน) จากนั้นใส่คีย์ที่ได้รับอีกครั้ง แล้วกด Activate ระบบจะรันอัปเกรดเป็น Pro สำเร็จ เมื่อเครื่องรีสตาร์ทเสร็จจึงค่อยเปิดเน็ตตามปกติครับ

เครื่องเคยลง Crack หรือโปรแกรม KMS เถื่อนมาก่อน?

วิธีแก้: เปิดโปรแกรม Command Prompt (cmd) โดยคลิกขวาเลือก Run as administrator แล้วพิมพ์คำสั่ง slmgr /upk กด Enter เพื่อถอนการติดตั้งคีย์เก่าออก จากนั้นจึงนำคีย์แท้ไปกรอกในหน้า Settings ตามปกติครับ
